## Abstract
The Smart Parking Management System is a web-based application designed to manage parking locations, slots, reservations, and parking operations. It provides drivers with slot availability and reservation workflows and administrators with parking inventory management, check-in/check-out, and occupancy summaries. The system was designed using software engineering artifacts including an SRS, design specification, UML/data diagrams, project plan, risk register, test plan, and traceability matrix.
