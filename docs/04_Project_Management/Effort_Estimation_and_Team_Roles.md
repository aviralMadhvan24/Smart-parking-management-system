# Effort Estimation and Team Roles

## 1. Illustrative effort estimate
These are planning estimates, not measured results. Adjust them to your actual team and scope.

| Work package | Estimated person-hours |
|---|---:|
| Requirements and proposal | 8 |
| Design and diagrams | 10 |
| Frontend | 18 |
| Backend/API | 22 |
| Database integration | 8 |
| Testing and fixes | 14 |
| Documentation and demo | 10 |
| **Total** | **90** |

## 2. Suggested roles
| Role | Responsibilities |
|---|---|
| Project coordinator | Scope, schedule, meetings, final integration |
| Requirements/documentation lead | SRS, traceability, final report |
| Frontend developer | Pages, forms, client-side validation, API integration |
| Backend developer | API, authentication, business rules, error handling |
| Database/testing lead | Models, indexes, test cases, test evidence |

In a small team, one person may hold multiple roles. Replace role labels with actual names and describe the work each member completed.

## 3. Estimation method
Use task-based estimation: split work into small tasks, estimate hours for each, sum the estimates, and add a reasonable contingency for integration and debugging. Compare estimates with actual hours after completion and explain major differences in the final report.
